# ModularUS

**Modular ultrasound systems and algorithms.**<br>
Open hardware, firmware, software, and intelligence for wearable and research ultrasound.

<br clear="left">

| Layer | Scope | Repositories |
|---|---|---|
| Transducers | piezoelectric films, acoustic stacks, probes | `td-*` |
| Circuits & systems | analog front-ends, pulsers, acquisition electronics, IC to board level | `el-*` |
| Firmware | ultra-low-power acquisition, embedded DSP, drivers | `fw-*` |
| Software | beamforming, reconstruction, interfaces, tooling | `sw-*` |
| Intelligence | learning on acoustic and multimodal biosignal data | `ml-*` |
| Metrology | acoustic characterization, hydrophone and impedance measurement, test rigs | `mi-*` |
